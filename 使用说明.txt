PDF 框选重命名 1.3.1
适用系统：Windows 10 / Windows 11，64 位。

报告编号审批模式（1.3 新增）
1. 导入文件夹，勾选左侧“报告编号审批模式”，后台开始预识别第一页。
2. 默认搜索第一页右上区域。如果位置不适合，点击“框选搜索范围”，
   在中间预览框一个较大的区域，包含“报告编号”及右侧号码；尽量同时包含委托编号、记录编号。
   搜索范围只需设置一次，会按各页的相对位置使用；编号在范围内有偏移可以自动定位。
3. 程序定位“报告编号”，提取末尾的 8 位日期 + 横线 + 流水号，例如 20250313-009。
   “定位规则”可修改定位文字、流水号位数（默认 3 位）及交叉核对开关。
4. 右侧显示候选编号和原始扫描中的编号截图；点击截图可放大。
   正确就按你已设置的“确认重命名”快捷键，或点击“确认通过并重命名”。
   软件此时才修改文件名，并自动转到下一个尚未审批/跳过的可见文件。
5. 有错可直接修改“新文件名”，选择其他编号候选，或用“手动框选 / OCR 选项”处理。
   也可以点击“跳过本份”。如果只想重新识别当前文件，点击“重试本份”。

审批与异常处理
• 预识别只生成候选，不会自动重命名任何文件；可逐份确认，或点击一键通过进行批量确认。
• 报告编号与委托/记录编号不一致、两个模型结果不同、找不到定位文字、
  编号日期无效、置信度较低或同目录候选重复，会标为“需检查”。
• 格式或交叉核对通过仍需人工审批，不保证没有 OCR 错误。
• 已有同名目标文件绝不覆盖；请修改名称或跳过。原文件名本来就正确时，确认只标记已审批。
• 后台识别异常会记录在对应文件上，继续处理其他文件。
• “暂停”停止安排后续预识别，当前已开始的任务可能仍会完成；已识别文件仍可审批。
• 你正在手动修改的名称不会被迟到的后台结果覆盖。
• 识别后文件若被其他程序修改，确认前会要求重新识别。
• 撤销重命名仍可恢复本次会话的改名操作；原名本就正确的审批不产生改名记录。
• 搜索范围、定位规则会保存。候选和审批状态只保留在本次会话，关闭后需重新预识别。
• 随附 report_samples 目录是五份虚构测试报告，包含位置偏移、倾斜、不一致和重复候选，可先试用。
• 取消勾选审批模式可继续原来的手动框选方式；手动方式切换文件仍清除精细框选区。

一键通过所有待审批（1.3.1 新增）
• 在审批模式点击“一键通过所有待审批（数量）”，立即通过并重命名当前所有“待审批”文件。
• 范围包含当前文件夹列表中被搜索筛选隐藏的待审批文件。
• 只纳入点击时已经预识别完成、无检查提示且未手动修改的项目。
• “需检查”“手动待确认”、已跳过及仍未识别完成的文件不处理；之后新识别的结果不会自动纳入本次。
• 执行中按钮会变为“停止批量通过”，可以停止尚未执行的部分，已完成的改名仍保留。
• 同名目标不会覆盖，文件已变化或改名失败的项目保留并标记为需检查，其他项目继续执行。
• 完成后显示实际改名、原名已匹配、失败及中止后未处理的数量，鼠标悬停结果文字可查看失败明细。
• 批量改名与逐份改名共用撤销记录，可以逐次撤销；本来名称已匹配的审批不产生改名记录。
• 执行期间暂时锁定文件夹切换、编辑、单份审批和撤销，完成或停止后恢复。

启动
双击“PDF框选重命名.exe”。无需安装 Python、Adobe Acrobat 或 OCR 软件。
整个软件文件夹需要保留；请勿只复制 exe，_internal 文件夹包含运行库及离线模型。

操作步骤
1. 将一个文件夹从资源管理器拖到软件窗口，或点击“选择文件夹”。
2. 左侧列出文件夹中的 PDF；默认包含子文件夹，可取消勾选。
3. 点击某个 PDF，中间显示第一页。多页文件只处理第一页。
4. 在文字周围按住鼠标左键拖出矩形框，松开后自动进行 OCR。
5. 核对右侧识别结果。可直接编辑识别结果，也可单独修改“新文件名”。
6. 点击“确认重命名”，在原目录修改这个 PDF 的文件名。

辅助操作
• OCR 自动结果去掉所有空格及空白字符，多行文字直接连接为文件名。
• 自动生成的文件名不含空格；在“新文件名”框手动输入的空格会保留。
• 系统不允许的文件名字符会自动清理，保留 .pdf 后缀。
• 文件名过长会截短，新名称会显示在按钮上方，请核对。
• 已存在同名文件时会提示，绝不覆盖。请修改新名称后再试。
• 默认重命名后跳到下一个文件；可取消勾选。
• “撤销上次重命名”可逐次恢复本次会话的历史名称。关闭软件后历史清空。
• 如果原名称被其他文件占用，或重命名后文件已修改或替换，将拒绝撤销。
• 快捷键可在右上角“设置”中自定义。详见下方“快捷键设置”。
• Ctrl+鼠标滚轮缩放，或使用上方 ＋ / −；“适合页面”恢复整页预览。
• 放大后可用滚动条移动页面，左键始终用于框选。
• 切换 PDF、重命名后自动切换时，保留当前缩放比例与浏览位置。
• 页面尺寸不同时按页面相对位置定位。“适合页面”可恢复整页预览。
• 左侧搜索框可按文件名筛选；外部增加或移动文件后点击“刷新文件夹”。

识别与文件保护
软件内置 PP-OCRv6 新版模型及 PP-OCRv4 原有模型，PDF 与识别区域均在本机处理，无需联网。
清晰印刷文字效果较好。模糊、手写、艺术字、竖排或严重倾斜的文字可能识别不准。
请在确认重命名前核对结果。过小的文字建议放大预览，框选时留少许空白边距。
置信度仅为模型参考值，不保证文字完全正确。
本软件只改文件名，不重新保存 PDF，不改变页面、签名或文件内容。
密码保护、损坏的 PDF 会显示预览失败；请先在其他软件中处理。
被其他程序占用或无写入权限的文件可能无法重命名，关闭占用程序或调整存放位置后重试。
默认不遍历符号链接与目录联接，避免循环或越出所选目录。
一次拖入多个文件夹时使用第一个文件夹。
关闭时若后台任务仍在处理，会提示稍后再关闭。

高清选区与双模型 OCR（1.2 新增）
右侧可以选择“新版模型 PP-OCRv6”“原有模型 PP-OCRv4”或“双模型对比”。
默认使用新版模型，首次识别需加载模型。识别效果不好时，可换原有模型或双模型对比。
双模型模式对同一个选区分别识别，在识别结果上方的候选框切换结果，选中的文字会填入新文件名。
不依据置信度自动判定谁一定正确；如果两种结果不同，请对照原文选用或编辑。
若某一个模型失败，另一个模型的可用结果仍会保留，并提示失败原因。

OCR 单独渲染框选区域，提供 300 / 450 / 600 DPI，默认 450 DPI。
大幅面 PDF 中的小字不再受整页缩图限制；超大选区会自动限制像素量，避免内存过高。
分辨率提高无法恢复原始扫描中已经丢失的细节。
图像方式可选：
• 高清原图：默认，保留原有颜色和细节。
• 增强对比度：适合文字颜色浅、背景灰的选区。
• 黑白扫描增强：适合扫描件、背景不均匀的选区；不合适时可切回原图。
“自动纠正轻微倾斜”默认开启，处理约 ±10° 内可检测到的文本行倾斜。
纠偏不是整页方向旋转；竖排、复杂图形或无明显文字行时可能不适用，可取消勾选。
改变模型、分辨率、图像增强或纠偏设置后，请点击“重新识别选区”。
识别选项会保存在当前 Windows 用户配置中，不影响快捷键设置。
窗口较小时，右侧操作区可上下滚动。

删除首位符号开关（1.2.2）
基于 1.2.0，取消保留框选区的改动；切换文件时清除框选区，缩放位置仍按原有方式保留。
右侧新增“删除识别结果开头的符号”，默认关闭；勾选后只删除第一个标点或符号。
例如：*合同 → 合同，##合同 → #合同，￥123 → 123；汉字、字母和数字开头不删除。
识别结果中间和末尾的符号保持原样，文件名仍按原有规则清理系统不允许的字符。
开关直接更新当前 OCR 候选、识别结果与自动文件名，不需要重新识别。
取消勾选可恢复当前候选的原始识别结果；切换候选不会重复删除开头符号。
开关会随识别选项保存，重启后继续生效。

快捷键设置（1.1 新增）
点击右上角“设置”，点击相应操作的快捷键框，直接按下所需的按键或组合键。
点击输入框右侧 × 可清除该操作的快捷键，点击“保存设置”立即生效。
同一按键不能分配给多个操作；发生冲突会提示，修改后再保存。
“恢复默认”先恢复页面里的默认值，点击“保存设置”后应用；“取消”不修改设置。
设置保存在当前 Windows 用户的配置目录，重启软件、换位置运行或升级后继续生效。
快捷键只在本软件内生效，不会设置系统全局热键。

默认快捷键
↑：上一个文件
↓：下一个文件
Ctrl+Enter：确认重命名
Ctrl+R：重新识别选区
Ctrl+Z：撤销上次重命名
Ctrl+O：选择文件夹
F2：编辑新文件名
Ctrl+0：预览适合页面
Ctrl+,：打开设置

在识别结果、搜索、新文件名等文字输入框中，方向键及常用编辑快捷键保留编辑功能。
如需在输入文字时切换文件，可把上一个/下一个设为 Alt+↑ / Alt+↓。
切换文件只遍历当前搜索结果，到头或到尾停止，不循环跳转。
切换时不会保存尚未确认的识别结果或新名称，请先完成当前文件再切换。
也可使用左下方“上一个 / 下一个”按钮切换。
